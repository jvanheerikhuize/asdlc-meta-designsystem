# SPC-0002 · Composed Molecules, Organisms, Templates, and Showcase Pages

Tier: **feature** · Readiness: **100%**

Builds on: SPC-0001

Layer composed Molecules (Search Bar, Form Field, Media Card), standalone Organisms (Site Header, Modal Dialog, Catalog Grid), responsive Templates, and a Lumen-inspired Showcase Page on top of the `SPC-0001` token and Atom foundation.

## Non-goals

- Backend persistence, media streaming playback, or user authentication flows.

## Requirements

### REQ-0004 · Molecules compose Atoms into single-purpose interactive groups with slot and event contracts (active)

Molecules (such as Form Field, Search Bar, and Media/Poster Card) MUST compose multiple Atoms through explicit content slots and emit high-level semantic events (such as search submission or card selection) without leaking internal Atom layout details to parent containers. A Molecule MUST use an existing Atom for each title, message, value or control it shows, as far as the limit of three kinds of Atom allows.

**REQ-0004#1**

```gherkin
Given a Search Bar Molecule composed of Label, Text Input, and Button Atoms
When the user enters a query and submits via keyboard or the action Button
Then the Molecule emits a single semantic search event carrying the current query value
```

**REQ-0004#2**

```gherkin
Given a Form Field or Search Bar Molecule whose value is set before it is placed in a view
When it is placed in the view and the user edits it
Then it first shows the value that was set and afterwards reports the edited value
```

**REQ-0004#3**

```gherkin
Given a clearable Search Bar Molecule with a query
When the user clears it with the clear control or Escape
Then the query is empty, the change is reported once, and focus stays in the input
```

**REQ-0004#4**

```gherkin
Given a Form Field Molecule inside a form
When the form is submitted or reset
Then the Form Field takes part like a Text Input
```

**REQ-0004#5**

```gherkin
Given a Theme Toggle Molecule
When the user activates it
Then it switches between dark and light and emits one semantic event with the new theme
```

Because:
- FCT-0001 (active): Atomic Design organizes interfaces into five strictly layered compositional tiers
- FCT-0007 (active): Encapsulated native components styled via shared design tokens scale across foundational tiers without external UI frameworks
- FCT-0010 (active): The design system uses six tiers with tokens as the first and Pages outside the shared package

### REQ-0005 · Organisms, Templates, and Pages assemble Molecules into responsive, accessible application views (active)

Organisms (Site Header, Modal Dialog with blurred backdrop and focus containment, Catalog Grid, and Data Table), Templates (structural page blueprints), and Pages (live showcase instances with realistic content) MUST compose lower-tier components into responsive views that preserve keyboard navigation, overlay dismissal, and clean slot boundaries.

**REQ-0005#1**

```gherkin
Given a Modal Dialog Organism opened from a Catalog Grid item
When the user presses the escape key or activates the backdrop close control
Then the modal closes cleanly and restores keyboard focus to the triggering element
```

**REQ-0005#2**

```gherkin
Given a Data Table wider than the available space
When a keyboard user focuses its labelled region
Then the table scrolls inside that region, the page itself does not scroll sideways, and header and cell semantics stay intact
```

**REQ-0005#3**

```gherkin
Given a Popover with a heading
When the user activates its close control
Then the Popover closes, focus returns to the trigger, and the close is reported once
```

**REQ-0005#4**

```gherkin
Given a Modal Dialog, Drawer or Toast
When the user activates its close control
Then the close is reported once
```

**REQ-0005#5**

```gherkin
Given a Data Table or Catalog Grid that is loading or has no items
When it is rendered
Then it shows a loading placeholder or an empty message in place of its items
```

**REQ-0005#6**

```gherkin
Given a Template in a narrow view
When its slots are filled
Then they stack without sideways scrolling, and a footer without content takes no space
```

Because:
- FCT-0001 (active): Atomic Design organizes interfaces into five strictly layered compositional tiers
- FCT-0004 (active): Initial Showcase Page validates Organism and Template composition via a Lumen-inspired Catalog Browser
- FCT-0007 (active): Encapsulated native components styled via shared design tokens scale across foundational tiers without external UI frameworks
- FCT-0010 (active): The design system uses six tiers with tokens as the first and Pages outside the shared package

## Technology Stack

# Technology Stack & Visual Binding

This document binds the technology-agnostic specifications in `.specs/records/` (rendered to `specs/`) to a concrete browser-native implementation and Lumen-inspired dark-first visual language.

Spec-Blueprint: asdlc-meta-specs@latest

## 1. Runtime & Architecture

- **Zero external runtime dependencies:** Plain HTML5, CSS3, and ES2022+ JavaScript. No React, Vue, Tailwind, or bundler required.
- **HTML (Web Components):** Native `<template>`, `<slot>`, `<dialog>`, and Custom Elements (`customElements.define`) using custom tags (e.g., `<ui-button>`, `<ui-input>`, `<ui-media-card>`, `<ui-modal>`, `<ui-navbar>`).
- **CSS (Design Tokens & Shadow DOM):**
  - Global CSS Custom Properties (`--color-*`, `--space-*`, `--radius-*`, `--font-*`, `--shadow-*`) defined at `:root` so tokens pierce Shadow DOM boundaries cleanly.
  - Native CSS nesting and encapsulated Shadow DOM (`attachShadow({ mode: 'open' })`) stylesheets for component-scoped styling.
  - Native `@media (prefers-reduced-motion: reduce)` fallbacks and optical label alignment (`text-box: trim-both cap alphabetic`).
- **Vanilla JavaScript:** Component classes extending `HTMLElement`, using `observedAttributes`, `attributeChangedCallback`, `connectedCallback`, `CustomEvent` dispatching, and ARIA attribute synchronization without a virtual DOM.
- **Verification:** `Spec-Blueprint` (`asdlc-meta-specs@latest`) `check --strict` for specification integrity and native browser / Node test runner checks for component behavior.

## 4. Tier Layout

```text
src/            # Shared package: tiers 1 to 5
├── index.js    # Zero-build ESM entry point registering custom elements
├── tokens/     # 1. tokens.css (--palette-* primitives, then semantic tokens), mkdocs-theme.css
├── atoms/      # 2. One native element each, imports nothing
├── molecules/  # 3. One to three kinds of atom, imports atoms only
├── organisms/  # 4. At least one molecule, imports atoms and molecules
└── templates/  # 5. Slots and CSS Grid, imports nothing
showcase/       # 6. The one page here, a consumer of src/ and catalog.json
```

- **Token rules:** components use `var(--token)` without fallbacks and do not derive values with `color-mix`, so `tokens.css` is mandatory. Only semantic tokens may use `--palette-*`. `--anchor-gap` and `--anchor-margin` must be in `px`, because scripts read them.
- **Exceptions:** media and container queries cannot read custom properties, so breakpoints are literals: `640px` (narrow) and `1023px` (drawer becomes modal). `0`, percentages, viewport units, `fr`, the keyword `transparent`, the state extremes `scale(0)` and `scale(1)`, and gradients made of tokens are not tokens.
- **Enforcement:** `tests/test_designsystem.py` checks imports, composition, raw values and unused imports.
