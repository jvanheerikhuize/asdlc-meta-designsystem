## Purpose
Provide a stable, low-friction consultation interface so agents working in any repository in the workspace can discover, query, and apply the design system's tokens, components, and Lumen-inspired UX/UI patterns consistently.

## Non-goals
- Automatic runtime injection into third-party repositories without explicit adoption.
- Framework-specific wrapper generation unless explicitly justified later.
