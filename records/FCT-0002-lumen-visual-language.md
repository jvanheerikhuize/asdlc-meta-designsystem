## Statement
The reference Lumen interface establishes a coherent dark-first aesthetic built on a low-luminance canvas, subtle warm top ambient highlights, high-contrast foreground text, translucent hairline borders, blurred overlay backdrops, and shimmer loading states paired with reduced-motion accessibility fallbacks.
